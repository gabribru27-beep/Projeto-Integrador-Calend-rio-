# Calendário Acadêmico SENAC

Este projeto foi criado como exemplo didático para ensinar estruturação de projetos web com PHP, HTML, CSS e JavaScript.

## Estrutura

- index.php: ponto de entrada do sistema
- includes/: arquivos reutilizáveis como header e footer
- pages/: conteúdo das páginas
- css/: estilos do projeto
- js/: scripts do projeto
- imagens/: arquivos de imagem

## Como executar

Abra o projeto em um servidor local com PHP, por exemplo:

```bash
php -S localhost:8000
```

Depois acesse:

- Se esti
butido do PHP: [http://localhost:8000/index.php](http://localhost:8000/index.php)
- Se estiver usando XAMPP/Apache: [http://localhost/CALENDARIO_SENAC/](http://localhost/CALENDARIO_SENAC/)
